## 4. Most important difference

The formatting part, which is the control, came out identical: both arms found the same 3+1 duplicates, 70 dates, 32 text numbers and 81 ticker fixes, and both flagged notes as a mixed-type column. Both also caught all 6 unit errors and both planted ±12% values, and neither fell for the META Q3-25 net income trap. The difference is in precision. Arm B matched every row to SEC XBRL through get_financials, used the same Q4 derivation as the key, and changed nothing that was correct, so its cleaned file matches the key 96/96. Arm A rebuilt quarters from press releases by subtraction, checked a few values only from memory, and "corrected" two values that were already right (GOOGL Q4-25 revenue and META Q4-24 operating income, each off by 1 against press-release rounding). Those two changes are harmless in size but are false positives at High confidence. In a cleaning task they would also overwrite good source data and add noise to the change log. B was also faster to verify (4 tool calls against 14 web calls).
