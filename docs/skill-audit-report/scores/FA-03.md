## 4. Most important difference

The outputs are almost the same. Every verifiable price, LTM revenue, growth rate and P/E is within tolerance in both arms, and the peer medians differ by 0.1x. Arm A got there by working around the blocked SEC API with 45 WebFetches: 31 calls to the XBRL concept API (5 errored), the 8-K exhibits, and price pages that sometimes disagreed with each other, such as ORCL's 10-14 close on only one source. Arm B used 35 stock-data calls plus 17 SEC fetches for D&A and debt detail. The one real gap comes from different definition choices. A priced on diluted weighted-average shares, so its market caps run 0.2-1.1% above the quote. A also netted AAPL's non-current securities, which pulls AAPL's EV 1% below B's. Neither arm had a data error.
