## 4. Most important difference

Both arms got every verifiable input right and arrived at the same beta, 1.10 on 60 observations. Arm A rebuilt it from Yahoo pages read through a summariser, and the result matched stockanalysis.com's published beta. Arm B computed it from get_price_history. The base value per share still differs by $34 (403 vs 369). The cause is modelling choices, not data: A included about $88.5bn of leases in debt, used a lower cost of debt, and set WACC at 10.5% against B's 10.7%. Both arms took the same FY2024/25 D&A figures from memory. The MCP mainly saved effort and made the inputs traceable, with one call each for FRED, quotes and price history instead of scraped pages. It did not change accuracy. A's same-day treasury.gov yield was actually one observation fresher than the FRED value B could reach.
