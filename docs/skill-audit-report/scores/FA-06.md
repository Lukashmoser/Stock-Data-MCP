## 4. Most important difference

The data inputs are almost identical: the same price, share count and dilution proxy, the same 2026-07-31 cash, the same LTM build and the same SOFR. Arm A matched B by reading the 8-K/10-Q and FRED pages directly. The only data gap is that A's HY OAS and 7Y yield are one FRED observation old (3.16% vs 3.25%). That is within tolerance and moves the notes coupon by about 40bp. The arms diverge on a judgement call about SBC, which the prompt asked them to state. A added SBC back, so it raised 55% more debt (12.3bn vs 7.9bn) and wrote a smaller equity cheque. B treated SBC as a real cost. The returns still come out close (IRR 9.5% vs 9.0%) because both exit at their own entry multiple. The MCP did not drive the gap.
