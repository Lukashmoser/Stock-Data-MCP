## 4. Most important difference

This test was expected to show a "High" gap, but the outcome is a tie on the rubric. Arm A found that stockanalysis.com publishes TTM financials and statistics for every ticker. With 30 fetches it reproduced B's MCP-built screen almost number for number, down to the same composite ranking and the same four ideas. The differences are in precision and confidence. A rounded mega-cap market caps and EVs to $10bn and marked every row M because everything came from one aggregator with no filing check. B built TTM figures from XBRL quarters and EV from balance-sheet debt and cash, and marked rows H. It still had to patch six debt lines from 10-Qs because the XBRL map lacks them, for example ORCL long-term debt. That patch is the only place where the MCP's coverage gap pushed B back to the web.
