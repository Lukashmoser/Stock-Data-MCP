**Which version produced a correct table without edits?**
- **Neither did, strictly.**
- **Skill A**, run as written (paste the raw tool output into the script), produced a silently degraded table. Its parser doesn't recognise get_price_history's `{columns, rows}` shape, so all three names came out PARTIAL with n/a for 1W, 1M and 52-wk. No error was raised. The tester then applied the reshape that A's own references/data_sources.md prescribes, without editing the script or the output, and the table was fully correct for A's "latest filing of any form" definition.
- **Skill B** ran end to end exactly as written: the tool names and parameters matched, it made 12 calls with no errors, and it needed no workaround. Every numeric column was correct, but one cell was wrong. META's "Latest SEC filing" showed n/a because limit=40 returned only insider forms. That cell should be at least the 8-K of 2026-07-29, and it was not flagged.
- **B came closer to "correct without edits":** 17 of 18 cells right, against 0 of 9 price-metric cells right for A before the reshape. A's failure is the more serious kind, because it hits every row of the core price metrics. That is a direct result of writing the skill without seeing the tool schemas (the MCP was off in arm A).

## 4. Most important difference

This test shows the MCP's effect on what gets built, not on numbers. Arm A could not see the tool schemas, so it wrote a generic parser and a guessed input contract, and tested it only on fictional data. Its Comparison Block honestly marks live integration as untested. In the follow-up, that guess failed silently on the real get_price_history shape: every price metric was blank, with no error. Arm B built against the live tools, with exact tool names, parameters and call budget. It tested on real AAPL and MSFT data (prices match R0c) and on an invalid ticker, and in the follow-up it ran cleanly with no workaround. B's one flaw, a hidden n/a for META's latest filing caused by its insider-form filter and limit=40, is narrower and easy to fix. A's flaw breaks the core of the skill.
