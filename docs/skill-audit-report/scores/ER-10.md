## 4. Most important difference

Arm B built the entire sector dataset from stock-data alone, with 52 calls and no web search, and hit every verifiable figure exactly. It also produced analysis that A's sources couldn't support: TTM aggregates, FCF erosion, debt build-up, and a multiple-versus-rates history from FRED. Arm A had to assemble the same table from 37 web calls across about 13 sites and filled Apple entirely from memory. It ended up with three misses: META capex on a different definition (marked High), the combined capex that follows from it, and an XLK return from an unverified window. A's market caps and reported figures are close to B's, and nothing in A's outputs carries B's distinctive values, so the accidental script run doesn't appear to have contaminated A's figures.
